## Goal
- Export AI chats (currently DeepSeek) to Markdown via Playwright Chromium + pywebview UI, no API keys, no AI post-processing

## Constraints & Preferences
- **pywebview** — UI layer (Export button, URL input, status); does NOT render DeepSeek inside
- **Playwright Chromium** — execution engine (separate process, crash-domain isolation)
- **No API keys** — manual login only through Playwright window
- **No built-in Ollama/tags/summary** — AI post-processing is external
- **Playwright event handlers — always non-blocking**, no `response.text()` inside; proven: blocks event loop → regression 78→43
- Output format: `raw/{title}_{source}_{date}_{hash10}.md` with `#### 👤 Вы` / `#### 🤖 AI`
- `schema_version: 1` in data structure

## Key Decisions
- **Playwright, not WebView2 for DeepSeek**: WebView2 crashes on DeepSeek SPA
- **API class separate**: pywebview WinForms introspection fails on objects with Playwright/Browser references
- **Playwright event handlers — non-blocking mandatory**: proven — `response.text()` → 78→43
- **Scroll Engine v3.1 instead of v2.1**: content convergence instead of scrollHeight/DOM-size metrics
- **78 — ceiling, not 43**: 43 was regression from `response.text()` in event handler. After removal — stable 78. Proven 9+ runs in 3 experiments
- **No client-side extraction layer gives >78**: DOM scroll (78) ✅, API `history_messages` (empty) ❌, JS State (`{}`) ❌, API Tracer (0 payloads) ❌, SSR (empty) ❌, CacheStorage (`{}`) ❌, localStorage (session only) ❌, Pagination (0 calls) ❌, JS bundles (runtime only) ❌
- **Timing Lock v1 instead of time-based barrier**: message-count convergence (selectors: `.ds-virtual-list [data-message-id], .ds-message`), not `innerHTML` — since React may not change DOM but change state
- **3-layer architecture (Engine/Config/Orchestrator) — premature**: system not stabilized. Only minimal incremental changes to current class
- **Diagnostics (SSR, cache, bundles) — not bottleneck**: experiments show 0.2-0.5s savings out of 73s. Scroll engine = 55s — only significant consumer
- **Session reuse — IMPOSSIBLE**: 4 navigation strategies (goto, href, CustomEvent, next.router.push) — all FULL_RELOAD or NO_NAV. DeepSeek does not support SPA routing between different chat UUIDs
- **Batch export = N independent full exports**, each ~73s for 78 messages
- **CLI must NOT change pipeline order, include diagnostics, use harness inside run loop**
